# INTENT — Auto-Promote : promotion automatique des documents de gouvernance

> **Contexte** : Cet intent formalise le mécanisme de promotion automatique des documents de gouvernance (ADR, Designs, INTENTS) quand les critères métier objectifs sont remplis. Il s'agit d'une brique nécessaire à l'Aufhebung : sans promotion automatique, la dette de traçabilité s'accumule et bloque les audits.

---

## 1. Conception du Mécanisme

### 1.1 Problème

L'écosystème `gerivdb/*` génère continuellement des documents de gouvernance :
- **ADR** : décisions architecturales
- **Designs** : motifs d'implémentation
- **INTENTS** : chemins d'action stratégiques

Actuellement, ces documents restent en `proposed` même après implémentation, créant une dette de traçabilité.

### 1.2 Solution

Introduire un moteur de promotion automatique qui :
1. **Scanne** les documents de gouvernance
2. **Vérifie** les critères objectifs de promotion
3. **Applique** la promotion si les critères sont remplis
4. **Génère** un rapport d'exécution

### 1.3 Architecture

```
unified-design/
├── engine/
│   └── auto_design/
│       └── auto_promote.py          # Moteur de promotion
├── designs/
│   └── auto-promote/
│       ├── adr-criteria.yaml        # Critères ADR
│       ├── design-criteria.yaml     # Critères Design
│       └── intent-criteria.yaml     # Critères INTENT
├── .kilocode/
│   └── hooks/
│       └── pre-commit-auto-promote.py  # Hook pre-commit
└── tests/
    └── test_auto_promote.py         # Tests unitaires
```
