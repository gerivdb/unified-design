## Description

Format de rapport standardisé pour toute session d'extraction d'artefacts depuis une conversation.

## Structure obligatoire

1. **Tableau compact des artefacts**
   - Colonnes : Nom/ID, Type, Statut, Description, Priorité, Confiance, Prochaine action
   - Un artefact = une ligne

2. **Graphe textuel des dépendances**
   - Format : `ARTEFACT_A -> [ARTEFACT_B, ARTEFACT_C]`
   - Identifie les dépendances amont/aval

3. **Top 5 des actions à plus fort levier**
   - Classement par : impact / effort
   - Format : `1. ACTION (impact: X, effort: Y)`

4. **Roadmap courte**
   - `Maintenant` : actions P0 immédiates
   - `Ensuite` : actions P1
   - `Plus tard` : actions P2

5. **Questions ouvertes et zones d'incertitude**
   - Liste numérotée des décisions bloquantes
   - Marquage `[HYPOTHÈSE]` pour toute hypothèse non validée

## Variante courte

Pour analyses rapides (< 5 artefacts) :

```
- Artefacts : [Nouveau X, Mise à jour Y]
- Dépendances critiques : X -> Y
- Action prioritaire : ...
- Question bloquante : ...
```
