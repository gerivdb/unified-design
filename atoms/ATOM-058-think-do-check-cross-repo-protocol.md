# ATOM-058 : Think-Do-Check Cross-Repo Protocol

## Description
Protocole de validation croisee avant toute action cross-repo : penser, faire, verifier.

## Regles
1. PENSER : lister les repos impactes
2. FAIRE : appliquer le changement atomique
3. VERIFIER : valider la coherence post-action

## Checkpoints
- P-001 : Liste des repos impactes documentee
- P-002 : Changement atomique applique
- P-003 : coherence validee post-action
