# ATOM-REJECT-WORK-PRINCIPLE

## Description

Reject Work — Inspiré de D:\GG-knox\engineering ideas\300-kimi-k3\2.md.

Principe de rejet : le travail qui ne respecte pas les critères de qualité, de conformité ou de pertinence est rejeté plutôt qu'accommodé.

## Règles

1. Tout livrable qui ne passe pas les critères de qualité est rejeté, pas corrigé a posteriori
2. Le rejet est préférable à l'accommodation (better reject than accommodate)
3. La raison du rejet est documentée avec les critères non satisfaits
4. Le rejet n'est pas une punition, c'est un signal d'amélioration
5. L'auteur du livrable rejeté est informé et peut proposer une version corrigée
