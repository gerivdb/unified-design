# ATOM-LEARNING-CURVE-EXPECTATION

## Description

Courbe d'apprentissage — Inspiré de D:\GG-knox\engineering ideas\300-kimi-k3\5.md.

Toute nouveauté (technologie, pattern, outil) a une courbe d'apprentissage. Cette courbe doit être évaluée et documentée avant adoption.

## Règles

1. Toute nouveauté doit être évaluée sur 3 axes : complexité, adoption, maintenance
2. La courbe d'apprentissage est documentée dans le design/atom correspondant
3. Si la courbe est trop pentu (> 3 mois pour maîtrise) → prévoir un plan de formation
4. Le ROI de la nouveauté doit justifier la courbe d'apprentissage
5. La courbe d'apprentissage est réévaluée après 6 mois d'usage
