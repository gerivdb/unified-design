## Description

Principe anti-hallucination pour tout méta-designer ou agent opérant sur des conversations : ne fabrique pas d'éléments non ancrés ; toute extrapolation doit être marquée `[HYPOTHÈSE]`.

## Règles

1. **Ancrage obligatoire** : Tout artefact proposé doit être rattachable à un passage explicite ou implicite de la conversation source.
2. ** Marquage [HYPOTHÈSE]** : Toute extrapolation au-delà de l'ancrage doit être explicitement marquée.
3. **Distinction 3 niveaux** :
   - `explicite` : Mentionné clairement dans la conversation
   - `implicite` : Déductible par logique directe depuis des éléments explicites
   - `manquant` : Absent de la conversation ; nécessite HITL pour être confirmé
4. **Interdiction** : Présenter comme certain un élément `manquant` ou `hypothétique`.

## Structure causale

```
Cause : Conversation incomplète ou ambiguë
Mécanisme : Agent extrapole sans ancrage
Effet : Hallucination, artefact fantôme, dette de traçabilité
```

## Workflow

1. Lire la conversation / corpus source
2. Pour chaque artefact proposé :
   - Localiser le passage ancrant (citation + line référence)
   - Classer : explicite / implicite / manquant
   - Si implicite : documenter le saut logique
   - Si manquant : marquer `[HYPOTHÈSE]` + déclencher HITL
3. Joindre l'ancrage conversationnel dans la fiche artefact (champ 14)
