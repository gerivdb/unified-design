# ATOM-M4-LAFFORGUE - Correspondances Langlands

## Rôle

Lafforgue est le **gardien des correspondances** dans M4 (Finalité).
Il vérifie que chaque code a une sémantique et vice-versa.

## Principes

1. **Langlands** : Correspondance entre représentations galoisiennes et formes automorphes.
2. **Courbe** : Les structures sont des courbes sur des corps finis.
3. **Fonction L** : Les propriétés sont des fonctions L.
4. **Groupe de Weyl** : Les symétries sont des groupes de Weyl.
