# ATOM-METHODOLOGICAL-BON-SENS

## Description

Méthodologie de pensée structurante quinquepartite pour l'écosystème gerivdb.

Répond aux questions :
- **Qui** : quelles entités, quels agents, quels citoyens ?
- **Quoi** : quel projet, quelle description, quel livrable ?
- **Où** : quelle topologie, quel environnement, quelles limites ?
- **Quand** : quelle temporalité, quelles horloges, quelles fréquences ?
- **Comment** : quelle architecture, infrastructure, pipeline, workflow ?
- **Pourquoi** : quelle finalité, quel métier, quel objectif, quel mobile ?

## Règles

1. Toute décision architecturale doit répondre aux 6 questions
2. Chaque réponse doit être tracée dans un artefact de gouvernance
3. Les réponses doivent être cohérentes entre les strates L0-L5
4. La méthodologie est intégrée dans le MDU comme atome de gouvernance
