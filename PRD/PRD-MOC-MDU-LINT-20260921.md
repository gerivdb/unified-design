# PRD-MOC — MDU Lint

**Repo** : `gerivdb/unified-design`  
**Strate** : L0-CANON

**Date** : 2026-09-21  
**Version** : 1.1 (évaluation utilité + périmètre)

---

## Contexte

Le MDU souffre d’anomalies structurelles qui passent actuellement inaperçues jusqu’au push :
- doublons d’IDs dans `meta-design.yaml`
- chemins ambigus (`.yaml` vs `dossier/design.yaml`)
- `status` non harmonisés (`ACTIVE`, `DRAFT`, `STANDARD`)
- `consumers: []` vide → pas de traçabilité descendante

Il n’existe pas de linter dédié pour détecter ces anomalies en amont.

## Mission

Créer un linter MDU qui vérifie, avant tout commit/push, la conformité structurelle du MDU : unicité des IDs, canonicalité des chemins, harmonisation des statuts, et complétude des cross-références.

## Livrables

1. **Script `tools/mdu-lint.py`**
   - Modes : `--strict`, `--warn-only`
   - Sorties : stdout + rapport JSON
   - Exit codes : 0 = conforme, 1 = erreurs, 2 = avertissements

2. **Hook pre-commit**
   - Bloque en mode `--strict` si erreurs détectées

3. **Workflow d’intégration**
