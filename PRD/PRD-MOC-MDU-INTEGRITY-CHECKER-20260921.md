# PRD-MOC — MDU Integrity Checker

## Contexte

Le MDU (`meta-design.yaml` + `catalog/*.yaml` + arborescence physique) présente des écarts structurels qui cassent la métacohérence :
- doublons d’IDs dans `meta-design.yaml` et `catalog/designs.index.yaml`
- ~65 designs physiques non référencés dans `meta-design.yaml`
- `catalog/atoms.index.yaml` incomplet (~78 atomes orphelins)
- chemins ambigus (`.yaml` racine vs `dossier/design.yaml`)
- `consumers: []` vide → pas de traçabilité descendante

Il n’existe aucun outil dédié pour vérifier en temps réel la cohérence de ces trois sources de vérité.

## Mission

Créer un skill MDU-integrity-checker capable de vérifier, avant tout push ou commit, que `meta-design.yaml`, les catalogues et l’arborescence physique sont mutuellement cohérents.

## Livrables

1. **Skill `mdu-integrity-checker`**
   - Entrées : `meta-design.yaml`, `catalog/*.yaml`, racine `designs/`, `atoms/`, `pipelines/`, `workflows/`, `primitives/`, `skills/`, `citizens/`
   - Sorties : rapport JSON + résumé Markdown
   - Règles : unicité IDs, existence chemins, complétude index, canonicalité `.yaml` vs `dossier/design.yaml`, `status` harmonisé

2. **Script CLI `tools/mdu-lint.py`**
   - Commande : `python tools/mdu-lint.py --strict`
   - Exit 0 si conforme, exit 1 si écarts critiques, exit 2 si avertissements

3. **Hook pre-commit optionnel**
   - Bloque le commit si `--strict` retourne un écart critique
