# ADR-2026-09-20-001 — Artifact Extraction MDU Extension

**Repo** : `gerivdb/unified-design`  
**Strate** : L0-CANON  
**Statut** : accepted  
**Date** : 2026-09-20  
**Acceptation** : 2026-09-21

## Contexte

Le méta-designer (`pipeline-anamorphique-capture`, `conversation-forensics-analyzer`) extrait des concepts depuis les conversations, mais sans cadre standardisé pour produire des artefacts de design cohérents. Il manque :

1. Une **grille d'extraction 16 champs** reproductible
2. Une **taxonomie de statut** (nouveau / màj / fusion / suppression / à confirmer)
3. Un **principe d'ancrage conversationnel** anti-hallucination
4. Un **format de rapport** standardisé

## Décision

Ajouter au MDU 4 atoms gouvernants + 1 primitive + 1 design pour formaliser l'extraction d'artefacts depuis les conversations.

## Atoms ajoutés

| Atom | Type | Rôle |
|------|------|------|
| ATOM-ARTIFACT-EXTRACTION-STATUS | Gouvernance | Taxonomie statut extraction |
| ATOM-CONVERSATION-ANCHORING | Gouvernance | Principe anti-hallucination |
| ATOM-EXTRACTION-REPORT-FORMAT | Convention | Format rapport standardisé |
| ATOM-CONFIDENCE-THRESHOLD (étendu) | Gouvernance | Cadre qualitatif confiance |

## Primitive ajoutée

| Primitive | Rôle |
|-----------|------|
| artifact-extraction-card | Grille 16 champs pour fiche artefact |

## Design ajouté

| Design | Rôle |
|--------|------|
| meta-designer-role | Rôle formalisé méta-designer |

## Conséquences

- **MDU** : `meta-design.yaml` mis à jour avec 4 nouveaux atoms + 1 design
- **Gouvernance** : `ATOM-ARTIFACT-EXTRACTION-STATUS` devient référence obligatoire pour toute extraction
- **Agents** : Tout agent produisant un artefact depuis une conversation doit utiliser la grille 16 champs

## Alternatives considérées

| Alternative | Raison rejet |
|-------------|--------------|
| Ne rien ajouter | Manque de standardisation → hallucinations, doublons |
| Ajouter seulement une convention | Pas de validation mécanique |
| Ajouter un atom unique | Grille + taxonomie + ancrage + format = 4 responsabilités séparées |
