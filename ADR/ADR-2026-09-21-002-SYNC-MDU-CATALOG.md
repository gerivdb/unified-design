# ADR-2026-09-21-002 — Sync MDU Catalog

**Repo** : `gerivdb/unified-design`  
**Strate** : L0-CANON  
**Statut** : proposed  
**Date** : 2026-09-21

---

## Contexte

L’arborescence physique du MDU évolue plus vite que les indexes :
- `catalog/designs.index.yaml` contient des chemins dupliqués
- `catalog/atoms.index.yaml` n’est pas à jour
- `meta-design.yaml` référence des chemins qui n’existent plus

Il n’existe aucun script de synchronisation automatique entre l’arborescence et les catalogues.

## Décision

Ajouter au MDU un script `scripts/sync-mdu-catalog.py` et un workflow `workflows/mdu-daily-sync.md` pour maintenir `meta-design.yaml` et `catalog/*.yaml` cohérents avec l’arborescence physique.

## Conséquences

- **MDU** : `meta-design.yaml` mis à jour avec le workflow et le pipeline
- **Outillage** : `scripts/sync-mdu-catalog.py` créé
- **Workflow** : `workflows/mdu-daily-sync.md` créé

## Alternatives considérées

| Alternative | Raison rejet |
|-------------|--------------|
| Ne rien ajouter | Dette de sync manuelle croissante |
| Synchronisation manuelle | Source d’erreurs, non reproductible |
| Script externe | Pas d’intégration MDU |
