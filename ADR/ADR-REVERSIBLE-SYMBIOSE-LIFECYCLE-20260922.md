# ADR-REVERSIBLE-SYMBIOSE-LIFECYCLE-20260922 — Reversible Symbiose Lifecycle

**Repo** : `gerivdb/unified-design`  
**Strate** : L0-CANON  
**Statut** : accepted  
**Date** : 2026-09-22

---

## Contexte

Le design `symbiose-reversible-plugin-architecture.yaml` établit la réversibilité comme invariant de premier ordre. Il manque une **primitive exécutable** qui implémente cet invariant sur le cycle de vie des symbiotes :

- **Formation** : contrat, lease, KG-L edges, WAZAA hello, WAL snapshot
- **Maintenance** : mesure bénéficeNet, heartbeat, renouvellement lease
- **Dissolution** : arrêt flux, release lease, révocation edges, WAZAA bye, WAL compact, IntentHash

La primitive doit garantir que **toute dissolution est coûteuse et tracée** (tension #1 résolue).

## Décision

Créer la primitive `reversible-symbiose-lifecycle` qui implémente le cycle de vie réversible des symbiotes gerivdb, avec :

- preconditions/postconditions par phase ;
- rollback explicite pour chaque phase réversible ;
- `dissolution_cost` documenté (planifié vs non planifié) ;
- événement ARGUS systématique pour dissolution non planifiée ;
- validation par commandes gerivdb existantes.

## Conséquences

- **Primitive** : `reversible-symbiose-lifecycle.yaml` opérationnelle et vérifiable
- **Auditabilité** : `dissolution_cost` rend toute dissolution tracée (planifiée ou non)
- **Réversibilité effective** : rollback par phase + WAL snapshot + replay déterministe
- **Observabilité** : événement ARGUS unique par dissolution non planifiée

## Alternatives considérées

| Alternative | Raison rejet |
|-------------|--------------|
| Pas de primitive de lifecycle | Réversibilité reste déclarative, pas exécutable |
| Dissolution sans coût de traçabilité | Aucune dissuasion pour dissolution non planifiée |
| ARGUS systématique par mesure | Overhead inutile ; dissolution suffit comme événement d'audit |
